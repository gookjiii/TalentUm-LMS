# Context for Gemini Canvas UI/UX Upgrade

This folder contains the essential context files from the `school_world` Flutter application. Please use these files to understand the current architecture, theme, and UI patterns, and generate a new upgraded Mobile UI/UX for the application.

## Files included:
- `ARCHITECTURE.md` and `DESIGN.md`: High-level overview of the app's structure and design guidelines.
- `pubspec.yaml`: Contains the current dependencies (e.g., Riverpod for state management, go_router, Google Fonts).
- `theme.dart`: The central place where the app's colors, typography, and theme definitions are located.
- `main.dart`: The entry point showing how the app is initialized.
- `school_widgets.dart`: A collection of reusable widgets currently used in the app.
- `onboarding_screen.dart` and `student_shell.dart`: Representative examples of existing complex screens to give you an idea of the current coding style and layout structure.

## Goal:
Please analyze these files and propose a modern, aesthetically pleasing, and highly interactive UI/UX upgrade. Provide code for the new screens/widgets, adhering to the Riverpod state management and the existing architecture where possible.
